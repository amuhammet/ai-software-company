# AI Software Company

Bu proje, çoklu ajanlı yazılım şirketi fikrini simüle eden bir Python başlangıç uygulamasıdır. Öncelik, tek büyük modele bağımlı kalmak yerine, her biri spesifik görevlerde uzmanlaşmış ajanların koordinasyonunu sağlamaktır.

Ana hedefler:
- CEO / Orkestrator
- Researcher
- Architect
- Developer
- QA Reviewer
- Post-Mortem Analyzer
- Self-Updater

Yeni katmanlar:
- LangGraph-based state machine
- Conditional edges for validation/rework loop
- Optional Redis/ChromaDB memory layer
- Docker sandbox execution
- Tavily / DuckDuckGo search support

## Hızlı başlatma

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.main "Yeni çıkan X kütüphanesini kullanarak bir e-ticaret botu yaz"
```

## İş akışı

1. CEO task alır ve hedefi belirler.
2. Researcher en güncel bilgi ve API belgelerini toplayıp özetler.
3. Architect mimari blueprint ve veri modeli çıkarır.
4. Developer modüler kodu üretir.
5. QA izolasyonlu sandbox içinde doğrulama yapar.
6. QA başarısızsa akış "fix" döngüsüne döner.
7. QA başarılıysa post-mortem ve self-updater çalışır.
8. Sonunda release akışı tamamlanır.

## Notlar

Bu sistem, gerçek üretim ortamı için tam bir otonom yazılım şirketi değildir; geliştirme ve operasyon için güvenli bir üretim öncesi taslak olarak düşünülmelidir. En önemli üretim katmanları şunlardır:
- LangGraph gerçek graph yapısı
- Ollama + Llama 3 / CodeLlama
- Tavily API
- Redis + ChromaDB
- Güvenli Docker sandbox
- GitHub Actions integration
